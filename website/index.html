Install on Debian, Ubuntu & Mint

One package. Electron is bundled — you never install Chromium separately.

  1. Download Get the latest .deb from the button above (or GitHub Releases).
  2. Install 
    sudo dpkg -i asperadock_*_amd64.deb
sudo apt-get install -f   # only if dpkg reports missing deps
  3. Launch Open Aspera Hub from your app menu, add your apps, mark your daily ones warm.

Package id stays asperadock so upgrades are smooth. The app you see is Aspera Hub.

FAQ

Is Aspera Hub really free?

Yes. 100% free for anyone. No subscription, no freemium wall.

Which Linux distros?

Built and tested for Debian / Ubuntu / Linux Mint (amd64). Other Debian-based desktops usually work with the same .deb.

How is this different from Rambox or a browser?

Hub is tuned for light multi-account work: warm/cold apps, isolated profiles, and far lower idle RAM than typical Electron suites — while still feeling like a real desktop app.

Will more apps be added?

Yes. The catalog can grow. Today’s focus is messaging, mail, and Zoho for company use.

Where do my logins live?

Sessions stay on your machine under your user profile. Clearing a session in Hub signs that app out locally.
