Running in about a minute

Download the .deb, install it, launch Aspera Hub from your app menu.

Debian Ubuntu Linux Mint amd64
install 
# Recommended — or double-click the downloaded .deb
sudo apt install ./asperadock_*_amd64.deb

# Or with dpkg, then fix any missing deps
sudo dpkg -i asperadock_*_amd64.deb
sudo apt-get install -f

The package is named asperadock (kept stable so logins survive updates) — the launcher and About screen show Aspera Hub. After install, updates arrive in-app from GitHub Releases.

Good to know

Is it really free?

Yes — free forever. No subscription, no trial wall, no ads. Open source under the MIT license.

Which Linux distros are supported?

Debian, Ubuntu, and Linux Mint (amd64). Other Debian-based distributions usually work with the same .deb.

How is it different from Rambox or a browser?

The warm/cold design keeps daily apps instant while letting the rest sleep — typically lighter on RAM — and it is Linux-first. You also get a real desktop shell: badges, tray, mute, focus, lock, downloads, pins, Forward, and isolated logins.

Where do my logins live?

On your machine, under your own user profile. Aspera Hub is a desktop app — there is no cloud account and no server of ours in the middle.

How does Aspera AI work?

Optional. Bring your own key (Gemini, Sarvam, Grok, and others). Select text in WhatsApp, Arattai, Gmail, or Zoho Mail to summarize or refine — including inside an open PDF preview.

How does it relate to TuxGenie?

Same team. TuxGenie is our AI Linux assistant; Aspera Hub is the warm workspace for the apps you use all day. You can install Hub from TuxGenie’s app catalog too.
