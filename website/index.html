Warm where it counts. Cold everywhere else.

A browser keeps every tab alive or discards them without asking; a big suite keeps everything running. Aspera Hub does neither — you decide what stays hot.

Warm apps

Mark the handful you use all day to keep warm — 5 by default, up to 7 in Settings stay fully loaded, so switching to WhatsApp or Gmail is instant, with no cold-start spinner.

Default 5 warm · raise to 7 in Settings · instant switch

Cold on demand

Everything else loads only when you click it, and can hibernate after about 45 minutes idle (configurable) — so the apps you rarely open aren't quietly holding memory.

Sensible on a ~16 GB laptop

A real desktop shell — not just tabs

The polish of a native app, wrapped around the web apps you already live in.

Separate logins

Named profiles keep sessions isolated, so several WhatsApp or Gmail accounts never share cookies. Zoho Mail is isolated the same way.

Notification center

Per-app unread counts, a global bell, and a notification center — mark all read, clear, or jump back to the chat. Inline quick reply works on Arattai. On WhatsApp it stays off while Safe Mode is on (the default).

Focus & mute

Silence notifications or clear every badge with a shortcut when you need to concentrate.

Jump anywhere

Switch apps with Ctrl+1…9, quick-search chats with Ctrl+/, find in page with Ctrl+F, Google the web with Ctrl+E.

Password lock

Lock the whole workspace behind a password (toolbar button or Ctrl+Shift+L), and auto-lock when your screen locks or your PC sleeps.

Downloads & tray

Pick a downloads folder, open files when they finish, keep Hub in the tray or close-to-tray. Copy the current page link from the toolbar.

Themes

System, light, dark, darkest, glossy or mint — plus density and icon size so the shell matches your desktop.

Safe auto-update

Updates come from GitHub Releases and are verified with SHA-256 before they're applied. Check from the toolbar or the menu.

Keyboard-driven

Reorder tabs, reload, print, toggle focus, hibernate, or lock — all from the keyboard. Most shortcuts remap in the Shortcuts panel (Hub menu). Ctrl+R is reserved.

Everyday tools — in the shell

Extensions, Google search, CRM lookup, and page tools sit in the Hub chrome — not in five extra browser windows.

Chrome extensions

Install from the Chrome Web Store into WhatsApp, Arattai, and other Hub apps. Toolbar puzzle icon opens the manager — paste a store link, then Install.

Google web search

Toolbar search or Ctrl+E opens a Google search popup. Not Ctrl+K — WhatsApp and Arattai already use that for chat search. Quick search (Ctrl+/) covers apps plus chats in currently loaded tabs. WhatsApp chat scrape/search stays off while Safe Mode is on.

Zoho CRM lookup

Optional. Select a name or keyword, right-click → look up matching Deals (stage, amount, account). Turn on in Settings → Integrations. Office fleets can pull secrets from a Fleet API so staff never paste Client ID/Secret onto each PC.

PDF preview

Open PDFs in Hub’s viewer instead of bouncing to a separate app. From Aspera AI you can also upload a PDF and summarize it.

Copy link & history

Copy the current page URL from the toolbar. Back / forward / reload work like a browser. Print the page with Ctrl+P.

Links as Hub tabs

Outbound links open as a real app-bar tab (never a blank popup). Zoho CRM / One / Books tabs can share one login so Sales and Leads stay side by side.

Reliable & secure — on your machine

Aspera Hub is a desktop app. Your WhatsApp and Zoho logins stay under your user profile. There is no Hub cloud account and no Aspera server in the middle.

  • SHA-256 verified updatesGitHub Releases only. A corrupted download is refused before install. This checks integrity (not code-signing) — it cannot stop a compromised GitHub release.
  • Isolated web appsPages run with contextIsolation and no Node. The Linux .deb starts Chromium with --no-sandbox so it launches reliably on Mint.
  • Password lockOptional whole-workspace lock; auto-lock when the screen locks or the PC sleeps. Shortcut: Ctrl+Shift+L.
  • Isolated partitionsEach profile is its own Electron persist session — no cookie bleed.
  • Single instanceOne Hub window per profile data dir — no accidental double sessions.
  • Open source MITRead it, modify it, share it. Free forever — no subscription, no ads.
  • Notes stay localAspera Notes and your AI keys never leave this PC unless you paste them yourself.
  • Error reportsCrash reports go to Sentry by default. Switch to Local only in Settings → Error reporting.

Good to know

Is it really free?
Yes — free, forever. No subscription, no trial wall, no ads. Open source under the MIT license. 100% free for life.
Which Linux distros are supported?
Debian, Ubuntu and Linux Mint (amd64). Other Debian-based distributions usually work with the same .deb. Tuned especially for Mint Cinnamon and XFCE fleets.
How is it different from Rambox or a browser?
You choose which apps stay warm. Browsers may discard background tabs without asking; heavy suites often keep everything loaded. Hub also gives you badges, a notification center, tray, mute, focus, lock, downloads, Notes, Chrome extensions, Google web search, and isolated logins — free and Linux-first. It does not forward chats between WhatsApp and Arattai.
Where do my logins live?
On your machine under ~/.config/Aspera Dock. Clearing a session in Hub signs that app out locally. There is no Hub cloud account. Crash reports go to Sentry by default — set Settings → Error reporting to Local only to keep them on this PC.
How many apps can stay warm?
By default 5 warm apps stay fully loaded. You can raise the cap to 7 in Settings. Everything else loads on click and can hibernate after about 45 minutes idle. Max 10 apps in the dock.
Does Aspera AI cost money?
Hub never charges. AI is optional and bring-your-own-key (Gemini, Sarvam, Grok, DeepSeek, SambaNova, OpenRouter, or Anthropic). Many providers offer free tiers. Keys stay on your machine. Polish and summarize never auto-send — you insert or paste, then send yourself.
What is Aspera Notes?
A floating copy pad (Ctrl+Shift+N) for links and repeated text. Copy from Notes, then paste where you want. Hub never sends from Notes.
Can I install Chrome extensions?
Yes. Open the Extensions toolbar icon, paste a Chrome Web Store link, and Install. Extensions run in Hub guest apps (WhatsApp, Arattai, Gmail, Zoho, and the rest of the catalog).
How does Zoho CRM lookup work?
Optional. Enable it in Settings → Integrations, then select a keyword in any app, right-click, and look up matching Deals (stage, amount, account). Office fleets can pull credentials from a Vercel fleet API so secrets are not pasted onto each PC.
Can Hub forward a WhatsApp message to Arattai?
No. Cross-app Forward is not available. Copy the text or file yourself, or use Aspera Notes as a paste pad. Hub never sends on your behalf.
Do Hub pins work on WhatsApp?
No. Hub pins are for Arattai only. Right-click an Arattai chat → Pin with Aspera Hub (up to 10). WhatsApp stays a human-driven tab — use WhatsApp’s own pins if you need them there.
What is WhatsApp Safe Mode?
It is on by default to reduce ban risk. Aspera AI, chat scrape/search, notification patches, and quick-reply send stay off on WhatsApp until you turn Safe Mode off in Settings → Security. Hub pins are not offered on WhatsApp. Arattai and mail apps are unaffected. Multiple WhatsApp tabs are fine when each uses a separate profile and phone number.
Can I add any website?
Today Hub uses the Aspera catalog only (WhatsApp, Arattai, Gmail, Zoho Mail/CRM/Books/WorkDrive/One). You can run multiple copies of the same app with separate profiles. The catalog will grow over time.

Honest limits

  • Primary package is amd64 .deb for Debian-family desktops.
  • Hub pins are Arattai only — not WhatsApp.
  • Hub does not forward messages between WhatsApp and Arattai.
  • Aspera AI (Polish, summarize, suggest reply) works on Arattai, Gmail, and Zoho Mail. WhatsApp AI requires turning Safe Mode off. Hub never auto-sends.
  • Notes is a copy pad — you paste yourself; Hub never sends from Notes.
  • Chrome extensions come from the Chrome Web Store into Hub guest apps.
  • Hardware acceleration is off on Linux so Hub starts reliably on Mint.
