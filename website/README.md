# Aspera Hub website — asperahub.com

Exact mirror of [tuxgenie.com/aspera-hub.html](https://www.tuxgenie.com/aspera-hub.html) — same design system, layout, and copy — hosted for **asperahub.com**.

Self-contained `index.html` (inline CSS/JS) plus `tuxgenie.svg` and `favicon-64.png`.

## Local preview

```bash
cd website
python3 -m http.server 5173
# open http://127.0.0.1:5173
```

## Deploy (Vercel)

Root Directory: `website` · no build command · add domain `asperahub.com`.
